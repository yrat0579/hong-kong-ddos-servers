## GoMami 香港节点：三网直连、到大陆 RTT 低于 30ms

官方文档对线路的描述很具体：香港节点对大陆的标称延迟为 **< 30ms**（日本 < 50ms，新加坡 < 70ms），整体宣传口径为 RTT < 50ms。回程走中国电信 CN2、中国联通 AS9929、中国移动 CMI 三条直连线路，并按来源 IP 智能选择最优回程，多上游冗余、自动故障切换。

这三条线的意义在于覆盖范围。CN2 是电信的精品骨干，比普通 163 骨干拥塞更轻；AS9929 是联通的精品国际线路，晚高峰吞吐更稳；CMI 是移动的国际网络。三条一起做，深圳的电信用户、上海的联通用户、北京的移动用户都能拿到相对低的延迟，而不是只优化其中一家的用户。

官方标称不等于实测。第三方测评 digvps 在 2025 年 10 月记录到“下午香港产品回程切 CN2、9929、CMIN2”，并提到当晚联通速率下降约 30%、伴随波动与重传；同年 8 月底同一家记录的湖南联通测速则从此前的 400–500Mbps 提升到接近 1Gbps。跨省链路本身波动大，这类数据只能作为线路存在与否的佐证，不能当 SLA。

## 被大流量攻击时会发生什么：黑洞 30–60 分钟，且不退款

这是挑香港高防时最容易被跳过、但直接决定“扛不扛得住”的条款。GoMami 官方文档写明：当实例遭受大规模 DDoS 攻击、并影响到同网段其他客户的正常使用时，系统会对该 IP 执行黑洞（null route），时长 30–60 分钟，自动解除，**无法人工干预**。黑洞期间所有进出流量被丢弃，服务暂时不可用。

配套的退款政策里还有一条：因 DDoS 攻击被黑洞的 IP，不在退款范围内。

这条条款对业务的实际影响比标称防御数字更直接。标 600G 说明的是清洗能力上限，黑洞条款说明的是“攻击影响到邻居时会怎么处理”。如果你的业务完全不能接受几十分钟的断连，那么任何带黑洞机制的方案都需要提前设计好备用入口——备用 IP、备用域名、CDN 回源切换，这些准备比多买 100G 防御更管用。

文档里也给了基础加固建议，包括用 fail2ban 自动封禁爆破 IP、把默认 22 端口改掉、用 iptables 限制 SYN 和 ICMP 速率。这些操作挡不住流量型攻击，但能减少被扫描和暴力破解的概率。
